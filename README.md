# MCode 应用介绍

**MCode** 是一款以键盘和命令面板为中心的 AI 编码助手，做成 Windows 桌面应用（Electron 打包，也有 macOS 和 Linux 的构建脚本）。

## 它是什么
你在本地打开一个项目目录，和 AI 对话，让它读代码、改文件、跑命令、查资料。

## 主要能力
- **多模型服务商**：接 Anthropic、OpenAI、ChatGPT 以及兼容接口。API 密钥以仅属主可读的权限存在本地，渲染进程拿不到密钥本身。
- **智能体工具**：读、写、改文件，列目录、glob、grep、执行命令，管理待办，抓取网页，向你提问，应用补丁。后端目录里还有联网搜索、Git、MCP 服务、记忆、Office 文档、LSP 等模块。
- **真实终端**：基于 ConPTY 的真 pty，有提示符和回显，`vim`、`top` 之类可以正常运行。
- **权限闸门**：只读工具直接运行。写文件、执行命令、联网都会先问你，并给出确切的命令或统一 diff。「始终允许」只在当前会话有效，不会持久保存。递归强删、直写磁盘、fork 炸弹、关机重启这几类命令直接拒绝，不再询问。
- **会话管理**：撤销与回滚、手动或自动压缩（1.1.5 新增压缩前冲刷记忆、压缩后注入结构化重建信息）、重启后保留会话。
- **主题与国际化**：内置 37 个主题，颜色由主题引擎从调色板派生；支持 18 种语言，包括阿拉伯语的整体镜像。
- **MCode Remote**：桌面端带一个远程网关，可以用手机浏览器打开驾驶舱，或使用原生安卓客户端（APK）远程查看和指挥会话。
- **自动更新检查**：目前只检查版本，不下载不安装，更新源还是占位地址。

## 常用快捷键
| 键 | 作用 |
|---|---|
| `Ctrl+K` | 命令面板，一切功能都能从这里到达 |
| `Ctrl+N` / `Ctrl+O` | 新建会话 / 打开项目目录 |
| `Ctrl+M` | 切换模型 |
| `` Ctrl+` `` | 终端抽屉 |
| `Ctrl+B` | 侧边栏 |
| `Ctrl+.` / `Esc` | 停止当前回合（`Esc` 只在输入框为空时生效） |
| `Y` / `A` / `N` | 权限询问中：允许一次 / 始终允许 / 拒绝 |

## 技术栈
Electron 42 + Vue 3 + Pinia + electron-vite，后端是同一进程里的 Node 服务，通过本机 WebSocket 与界面通信。智能体循环是手写的流式循环，每个文本增量、工具状态和权限询问都实时发布。质量靠大量专项检查守着（主题、i18n、MCP、沙箱路径、工具、会话、终端、提示词等），完整 smoke 测试最近一次记录是 7900 项通过。
