MCode Remote: the composer and the list indent, both measured

Composer: verified on the pad at 37.6 / 14.4 dp against the reference 36.8 /
13.2, the difference being the hairline and its antialiasing. It was 8.0 / 329.2
before the fix, i.e. running the pane edge to edge.

List indent: 8.8 for the first level, 20.4 for each one under it. Measured off
A_claude.png, whose top-level bullet starts at 48.8 dp and whose nested ring at
69.2 against a prose edge of 40.0 - so 8.8 and 29.2, and 8.8 + 20.4 = 29.2. The
old depth * 16 put the first level flush with the prose (a list looked like more
paragraphs) and stacked each level only 16 in.

The nesting itself could not be seen on glass: the pad has no conversation
containing a nested list, and adb input text does not reach a Compose field, so
the reply could not be provoked. The two numbers above are the reference measured
at both levels, and the arithmetic is checked against both.

Also set on the device, because a sleeping pad costs a round trip every time:
screen_off_timeout maxed, lockscreen.disabled 1, lock_screen_lock_after_timeout
maxed, screensaver off. It runs on battery, so Android still sleeps it - that
needs power, which stay_on_while_plugged_in cannot substitute for - and
.workbuddy/keepawake.py nudges it awake on a loop instead.
