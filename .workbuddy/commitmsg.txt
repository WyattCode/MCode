MCode Remote: 最近记录 exists, and it is not Code

Claude opens on a flat list of conversations called 最近记录, and Code - the one
with the 设备 panel, the capsule and the cards - is a separate destination in the
drawer. This app had one Sessions mode doing both, so the home list carried a
device block, drew every row as a card, and said 已连接 · Remote control under
every title where the reference says when it happened.

Split: LeftMode.Recent is the new default and the drawer's first row. Code keeps
LeftMode.Sessions and its cards. Both share the column's chrome through one
isListPage flag; only the list's skin and the device block differ.

Measured on the home list, then applied:

Search field is permanent there - 336 by 40, edge at x 12.0 - and absent from
Code. It was rendered only once a search was set, so the home page drew no
search at all.

Rows are flat: no plate, no hairline. The mark sits at 26.0..36.4 against the
reference's 26.0..37.6, off a 1.6 row inset.

Title is 18sp and the time is 14sp on its own line under it, both left aligned -
the reference's title ink is 12.8 tall with the time 10.0 below it. The row drew
15sp with the timestamp at the trailing end, and drew it twice once both paths
ran.

Icon column is 23.6 on the flat rows, not the cards' 36 - different pages'
geometry, and the 36 put the home title at 77.6 when the reference has 49.6.
