MCode Remote: the card's second line, and a spinner that never showed

The reference's conversation card carries 「已连接 · Remote control」 under its
title, in #296118 with a small laptop mark before it - 12.4 dp of ink starting at
78.0, which is the title's own left edge. Ours left that half of an 82 dp card
empty, so the row was one line of text floating in a tall frame. The line is in
now, and it says 已断开 in the muted colour when the link is down.

The mark at the card's start is a turning half-arc for a live conversation, not
the `</>`. That branch existed but tested `s.running || s.directory.isNotBlank()`,
so a running conversation that works in a project - which is most of them - took
the code mark and the spinner could never appear. Running is checked first now.

Both are visible side by side against A_claude.png: this column's Code title, 设备
label, 添加设备 capsule, 会话 heading and status-carrying card now sit where the
reference puts them.
