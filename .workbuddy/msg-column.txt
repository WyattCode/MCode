MCode Remote: a reading column, not a full-width pane

The transcript was running edge to edge. Measured off Claude's chat pane - not
its Code pane, which is a different layout and the one I had been reading from
for the last three passes:

  text left edge   1274px  = 99.5dp in from the pane
  column width     ~577dp inside a 775dp pane
  disclaimer       1274px, 46px of glyph = 13sp, level with the reply

Ours started at 1016 - 13dp of padding - so every reply was 200px wider than the
reference's and its line length half again as long. That is the largest single
difference left in the transcript, and it explains why the same words wrapped
differently.

Two corrections in one: the column is centred now, and the footer line exists.
Claude ends a turn with 「Claude 是 AI，可能会出错。」 level with the reply's own
left edge; nothing said it here, so the transcript simply stopped. It is drawn
once per turn, on the last answer, not after each update within one.

Measured after: the disclaimer sits at 1263 against 1274, 3.5dp of drift.

The lesson this pass cost me: I had been measuring the Code screen and calling
it the chat screen. They share a palette and nothing else - different column,
different indent, and the composer's send disc is a voice button there. The
Code pane's numbers are not the chat pane's numbers, and three commits went by
before I noticed.
