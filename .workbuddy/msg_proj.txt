MCode Remote: the project page looks like a page, not an error

Claude's project page opens on a large outlined folder with 「暂无项目」 and a
sentence under it saying what will appear there, and it closes with a black
「+ 新建项目」 capsule. This page printed one small grey line - 「会话还没有目录
信息」 - which reads as a fault rather than as a page waiting to be filled, and
had no way at all to add a folder, though `project.add` has been in the protocol
all along.

The empty state is now the icon and the two lines, at Claude's sizes (63dp
folder, 15sp title, 13sp sentence), and the capsule opens a field for a
directory path and sends `project.add`. The desktop opens a native folder picker
here; a phone has no such dialog, so the path is typed.

Build: gradle assembleDebug, installed on the pad (M367FC); the page listed the
four folders this account has.
