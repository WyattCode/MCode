## 第五轮：把「创建 PR」接上

之前几轮都记着「点击是空的，网关没有创建接口」。其实参考件的按钮也不是自己创建——**它打开 forge 的 compare 页面**，让用户在网页上确认标题正文。所以这件事可以做：

- remote 从 `.git/config` 拿（`file.read` 能读，239 字节的文本）
- branch 从 `git.status` 拿
- `pullRequestUrl(remote, branch)` 拼 URL：GitHub `/compare/main...branch`、GitLab `/-/compare/`；`git@host:o/r.git` 先转 https；分支里的 `/` 转 `%2F`

**挖出一个真 bug**：`gitRepo` 和 `prUrl` 原本只在「改动面板」打开时才查询。普通会话里从没查过，于是 `gitRepo` 恒为 false，即使身在 feature 分支的仓库里也不画按钮。改成按会话目录挂 `LaunchedEffect`。

**验证方法值得记**：先用日志探针（`Log.i`，不是 Toast——Toast 会被后续重组刷掉）看到 `screen repo=true ... url=...` 与 `turn gitRepo=false` 并存，才定位到状态没被赋值。URL 形状用公开仓库验：`torvalds/linux` 的真分支返回 200、假分支返回 404 —— 而私有仓库连首页都 404，所以之前那次 404 什么也证明不了。
